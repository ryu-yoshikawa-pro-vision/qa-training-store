# 学習工数参考

## 目的

この文書は、テスト自動化カリキュラムの学習計画を立てる際に参照する工数の目安をまとめたものです。

対象としては、手動テストの実務経験はあるものの、プログラミング、JavaScript / TypeScript、Playwright、CLI、Git、GitHub、CIの経験がない受講者を想定しています。

本書の工数は、従来のPlaywright・Maestro中心の教材構成をもとにした参考値です。2026年10月の改訂で追加したOpenCode・qa-workflow-skillsの実習を反映していません。受講実績から算出した統計値でもありません。AI演習と既存課題の重複を考慮して再試算するまでは、本書の数字だけで新カリキュラムの所要時間を確定しないでください。

各セクションの「標準工数の想定」は、想定受講者が標準的な進度で学習する場合の計画用の幅です。「全体の想定範囲」は、初学者ごとの試行錯誤や復習量の差を幅広く考慮した参考範囲であり、通常の学習計画における下限・上限としてそのまま用いることは想定していません。

教材理解、演習・実装、試行錯誤・復習の各工数は、活動ごとの目安です。各項目の最小値や最大値が同時に発生するわけではないため、内訳の単純合算とセクション全体の標準工数の値は一致しない場合があります。

なお、依存関係のダウンロードやビルド、GitHub Actionsのキュー待ち・実行待ちなど、受講者本人が操作していない待機時間は学習工数に含めません。初回の環境準備工数は別途記載しています。

## 参照時の扱い

ここに記載した工数はカリキュラムの規定値として固定するものではなく、学習計画を策定するための参考値です。

通常の計画作成には「標準工数の想定」を用い、「全体の想定範囲」は受講者ごとの進度差・試行錯誤の幅を見極めるための参考情報として活用してください。

教材、演習課題、完了条件、学習資材などに改訂があった場合は、改訂後の内容に合わせて工数目安を見直します。
