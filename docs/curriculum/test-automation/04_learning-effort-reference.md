# 学習工数参考

## 目的

この文書は、テスト自動化カリキュラムの学習計画を立てる際に参照する工数の目安をまとめたものです。

対象は、手動テストの実務経験はある一方で、プログラミング、JavaScript / TypeScript、Playwright、CLI、Git、GitHub、CIの経験がない受講者を想定します。

工数は、現在のリポジトリにある教材、演習、ワークブック、学習用資材、自己確認、完了条件、習熟度評価基準（Competency Rubric）の対象範囲を限定したレベル2（`bounded Level 2`）を基準にした現時点の想定です。受講実績から算出した統計値ではありません。

各セクションの「標準工数の想定」は、指定した受講者が通常の範囲で学習する場合の計画用の幅です。「全体の想定範囲」は、初学者ごとの試行錯誤や復習量の差を広く含めた参考範囲であり、通常の学習計画の下限・上限としてそのまま使うことは想定していません。

教材理解、演習・実装、試行錯誤・復習の各範囲は、活動ごとの目安です。各項目の最小値・最大値が同時に発生する前提ではないため、内訳の単純合算とセクション全体の標準工数は一致しない場合があります。

依存関係のダウンロード、ビルド、GitHub Actionsのキュー待ち・実行待ちなど、本人が操作していない時間は学習工数に含めません。初回環境準備は別に記載します。

## 参照時の扱い

この工数はカリキュラム内容を固定する仕様ではなく、学習計画を作成するための参考値です。

通常の計画では「標準工数の想定」を使用し、「全体の想定範囲」は受講者ごとの個人差を広く確認するための参考値として扱います。

教材、演習、完了条件、学習用資材が変更された場合は、変更後の内容を基準に見直します。
