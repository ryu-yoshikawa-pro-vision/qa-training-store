# 検証・メッセージ設計

UIに表示する文言の正本は`ui_content_dictionary.md`です。本ドキュメントでは、入力ルールと動的メッセージの構造を定義します。

## 1. 基本ルール

- UI上で即時バリデーションを行い、ユースケース層でも同一のビジネスルールを再検証する。
- エラーサマリーと各項目のエラーを関連付ける。
- 送信エラー（Submit Error）の発生時は、最初の入力フィールドではなくエラーサマリーにフォーカスを当てる。
- エラーサマリー内のリンクから該当フィールドへ移動できるようにする。
- システム内部の例外（Exception）やデータベース名などを利用者へ表示しない。
- メッセージには、現在の状態・原因・次の操作を可能な限り明記する。
- UI表示は日本語を基本とし、ドメインの内部値をそのまま表示しない。

## 2. 主な入力

| 項目 | 入力ルール |
|---|---|
| 検索キーワード | 前後トリム後で0〜100文字。サジェスト表示は2文字以上 |
| メールアドレス | 必須、最大254文字。前後トリム・Unicode NFKC正規化・ロケール非依存の小文字化を行った後、一般的なメールアドレス形式に合致すること。一意（重複不可） |
| パスワード | 必須、8〜72文字 |
| 表示名 | 必須、1〜100文字 |
| 郵便番号 | 半角数字7桁。学習用辞書に一致した場合のみ候補を提示 |
| 住所ラベル | 必須、1〜50文字 |
| 宛名 | 必須、1〜100文字 |
| 都道府県 | 必須、1〜20文字 |
| 市区町村 | 必須、1〜100文字 |
| 住所1 | 必須、1〜200文字 |
| 建物名・部屋番号 | 任意、0〜100文字 |
| 電話番号 | 半角数字10〜11桁 |
| 商品名 | 必須、1〜120文字 |
| `productCode` | 必須、1〜50文字。前後トリム・Unicode NFKC正規化・ASCII大文字化を行った後、`[A-Z0-9_-]+`形式に合致すること。一意（重複不可）。保存および表示には正規化後の値を使用 |
| 短い説明 | 任意、0〜200文字 |
| 商品説明 | 任意、0〜5,000文字 |
| カテゴリー名／ブランド名 | 必須、1〜80文字。前後トリム・Unicode NFKC正規化・小文字化・連続空白の圧縮を行った比較キーにより、スコープ内で重複不可 |
| SKU | 必須、1〜50文字。前後トリム・Unicode NFKC正規化・ASCII大文字化を行った後、`[A-Z0-9_-]+`形式に合致すること。一意（重複不可）。保存および表示には正規化後の値を使用 |
| SKU構成 | 下書き（draft）を含め、有効なSKU（active SKU）が1件以上存在すること。バリエーションなしの場合は有効なSKUがちょうど1件、バリエーションありの場合は有効なSKUが1件以上 |
| バリエーション軸名 | バリエーションありの場合は必須、1〜30文字 |
| バリエーション選択肢 | バリエーションありの場合は必須、1〜80文字。前後トリム・Unicode NFKC正規化・小文字化・連続空白の圧縮を行った比較キーにより、同一商品内の有効（active）な選択肢間で重複不可 |
| 価格 | 1以上の整数 |
| セール価格 | 通常価格未満であること。設定する場合は開始日時・終了日時の両方が必須で、開始日時＜終了日時であること |
| 購入上限 | 1〜99の整数 |
| 新規SKUの初期在庫 | 0以上の整数。新規SKUは有効（active）固定。既存SKUの在庫数は商品フォームから編集不可 |
| 数量 | 1〜99の整数、かつ購入上限数および在庫数以下 |
| 最低評価フィルター | 1〜5の数値 |
| レビュー評価 | 1〜5の5段階評価（ラジオボタングループ） |
| レビュータイトル | 任意、0〜120文字 |
| レビュー本文 | 必須、1〜1,000文字 |
| 在庫調整理由 | 必須、1〜200文字 |
| 配送会社 | 発送処理時に必須、1〜100文字 |
| 追跡番号 | 発送処理時に必須、1〜100文字 |
| 商品画像アセット | マニフェストに登録済みの`assetId`であること。最大3件まで、同一商品内で`assetId`の重複不可。画像0件は下書き（draft）のみ許可、1件以上の場合はメイン画像（Primary）がちょうど1件設定されていること。代替テキスト（Alt Text）は1〜120文字。新規の関連付けは有効（active）な画像のみ可能で、既存の無効（inactive）な画像の関連付けは維持のみ可能 |

## 3. エラーコードとメッセージ例

`ApplicationError.messageKey`には、原則として`error.<Code>`（例: `error.AUTHENTICATION_FAILED`）を使用します。標準的な日本語メッセージは以下のとおりです。

| Code | メッセージ |
|---|---|
| AUTHENTICATION_FAILED | メールアドレスまたはパスワードを確認してください。 |
| LOGIN_TRANSACTION_FAILED | ログイン処理を完了できませんでした。カートの内容は保持されています。もう一度お試しください。 |
| ACCOUNT_SUSPENDED | このアカウントは利用停止中です。 |
| ACCOUNT_WITHDRAWN | このアカウントは退会済みです。 |
| PERMISSION_DENIED | この操作を行う権限がありません。 |
| OUT_OF_STOCK | この商品は在庫切れです。 |
| INSUFFICIENT_STOCK | 選択した数量を用意できません。在庫数を確認してください。 |
| PRICE_CHANGED | 商品価格が変更されました。変更内容を確認してください。 |
| CART_VERSION_CHANGED | カートの内容が更新されました。もう一度確認してください。 |
| CHECKOUT_EXPIRED | 購入手続きの有効期限が切れました。カートからやり直してください。 |
| PAYMENT_FAILED | 支払いを完了できませんでした。注文詳細から再試行できます。 |
| CONFLICT | 他の操作で内容が更新されました。最新の内容を確認してください。 |
| STORAGE_WRITE_FAILED | 保存できませんでした。入力内容を保持したまま再試行してください。 |
| IMAGE_ASSET_NOT_FOUND | 選択した画像を利用できません。画像一覧を更新して選び直してください。 |
| IMAGE_ASSET_INACTIVE | この画像は新しく選択できません。別の画像を選んでください。 |
| PRODUCT_HAS_REFERENCE | この商品はカート・注文・レビューから参照されているため削除できません。非公開または販売終了にしてください。 |
| VARIANT_HAS_REFERENCE | このSKUは利用履歴があるため削除できません。無効化してください。 |
| QUANTITY_LIMIT_EXCEEDED | 選択した数量は在庫または購入上限を超えています。 |

## 4. 検索・フィルターのメッセージ

- 検索結果0件: 「条件に一致する商品がありません」を表示する。検索キーワードの変更、フィルター全解除、全商品一覧へのリンク（アクション）を提示する。
- サジェスト候補0件: 「候補がありません。Enterでこのキーワードを検索できます」を表示する。
- フィルターの候補件数が0件の場合: 件数`0`を表示し、チェックボックスや選択肢（Option）を選択不可にする。
- URLの無効なクエリ: 既定値へ正規化し、利用者に対して技術的なエラーを表示しない。

## 5. フォームエラー概要

```text
入力内容を確認してください
- 郵便番号を7桁で入力してください
- 電話番号を10～11桁で入力してください
```

各エラー項目をリンクとし、クリックまたは選択すると該当の入力フィールドへフォーカスを移動させます。

## 6. 成功・処理結果のメッセージ

- カート追加: 「商品をカートに追加しました」＋「カートを見る」リンク。
- 保存完了: 「変更を保存しました」。重要な更新内容はページ内のステータス表示にも反映する。
- 一括更新（Bulk）: 「8件を公開しました。2件は更新できませんでした」＋失敗対象へのリンク。
- 注文完了: 注文番号、合計金額、注文詳細へのリンクを画面内に表示する。
- トースト通知（Toast）はあくまで補助的な通知とし、重要な処理結果を通知する唯一の手段にしてはならない。

## 7. 未保存の変更・破壊的操作に関するメッセージ

- 未保存のまま画面離脱する場合: 「保存していない変更があります」＋「保存して移動」「破棄して移動」「編集に戻る」の各選択肢を提示する。
- 商品ステータスの一括変更: 対象件数、変更後のステータス、実行に伴う影響を確認する。
- 危険な操作（削除などのDanger操作）: 確認メッセージ内に対象の名称を含める。

## 検索文字列の正規化

商品名、短い説明、カテゴリー名、ブランド名、検索キーワードには、同一の正規化関数を適用します。処理内容は以下のとおりです。

- 前後空白のトリム（Trim）
- Unicode NFKC正規化
- ロケール非依存の小文字化
- 連続する空白の半角スペース1文字への圧縮
