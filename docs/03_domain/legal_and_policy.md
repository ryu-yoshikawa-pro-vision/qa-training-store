# 規約・ポリシー表示

## 1. 位置付け

フェーズ1では、学習用アプリであることを説明する静的ページとして提供します。バージョン付きの同意履歴管理や、法的契約の再現は行いません。

| Route | 表示名 |
|---|---|
| `/legal/terms` | 利用規約 |
| `/legal/privacy` | プライバシーポリシー |
| `/legal/commerce` | 模擬取引表示 |

## 2. 共通注意

- 本アプリはソフトウェアテストおよびテスト自動化の学習用模擬ECです。
- 実際の商品販売、決済、配送、契約締結は行いません。
- 実在する氏名、住所、電話番号、パスワード、カード情報を入力しないでください。
- データはブラウザまたは端末内に保存され、リセットやデータ削除によって消失します。
- 認証や権限は疑似実装であり、本番サービス相当のセキュリティは提供しません。

## 3. プライバシー表示

- アナリティクス、外部エラートラッキング、外部決済、外部業務APIは使用しません。
- Web版の業務データはIndexedDB、セッションIDはローカルストレージへ保存します。
- ホスティングサービスには、通常のアクセスログが残る場合があります。
- ダミーデータのみを使用してください。

## 4. 模擬取引表示

| 項目 | 表示内容 |
|---|---|
| 販売事業者 | Scenario Shop（架空） |
| 所在地・連絡先 | 実在情報なし |
| 販売価格 | 画面表示の日本円（税込）ダミー価格 |
| 商品代金以外 | ダミー送料500円（条件により無料） |
| 支払方法 | TEST-* 模擬決済のみ |
| 商品引渡し | 実配送なし（管理画面での状態変更のみ） |

## 5. 表示位置

- ストアフロントのフッター
- 全画面ヘッダーの小さな「テスト環境」バッジ
- ログイン、サインアップ、カート、チェックアウトの注意表示
- ホーム画面の学習用環境説明

バージョン付きの規約同意履歴は、フェーズ3で必要性を再評価します。
