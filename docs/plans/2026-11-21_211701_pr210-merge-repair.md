# PR #210 main 取り込み後の競合・検証エラー修復計画

## 0. 依頼概要

- 依頼内容: `product/scenario-shop-maintenance`上の進行中mergeを維持し、残存競合と確認済みの検証エラーを最小限修正する。
- 背景: PR #210の製品変更を保ったまま、`origin/main`取り込み後のmerge結果をcommit可能な状態にする。
- 期待成果: 競合なし、型とNativeコンポーネントテストの修復、契約テストのPowerShell失敗の原因評価、指定ゲートの結果と残件の根拠ある報告。

## 1. ゴール / 完了条件

- ゴール: 製品仕様やPR #226の変更を損なわずに、原因を確認できたテスト不整合だけを修復する。
- 完了条件（DoD）:
  - branchが`product/scenario-shop-maintenance`でmerge状態を維持している。
  - unmerged entryが0件で、`MERGE_HEAD`は保持されている。
  - 在庫境界値テストは`pageSize: 50`で仕様どおり4件の対象IDを検証する。
  - Nativeの非同期`render()`利用不整合を修正し、個別と対象ファイルのテストを実行する。
  - integration、component、contracts、typecheck、format/diff検査の実行結果を正確に記録する。
  - PowerShellテスト6件についてWSL/Windows環境を区別し、スクリプト変更の要否を根拠付きで判定する。
  - 修正ファイルのみを確認してstageし、commit/merge continuation/pushは実行しない。

## 2. 現状理解と前提

- 現状理解:
  - 初回の読み取り専用Git確認ではbranchは`product/scenario-shop-maintenance`、merge進行中、競合はすでに解消済みで、未解決パスとindex stage entryは0件。`git diff --cached --check`と`git diff --check`は成功。
  - merge indexにはmain側で廃止済みの`tests/contracts/codex-safe-run-manifest-sync.test.ts`削除が含まれる。再追加しない。
  - PR #210のオンラインheadは`cf242b30bd100c8f5dedbb623ad8ed1061033e3b`。そのWeb CI #44044849893はtypecheck、format、component suiteが失敗し、Vitest integration/contractsとChromium E2Eは成功。Mobile App CI #44044850093はNative component jobが失敗した一方、Android/iOSのbuild jobsは成功。
  - 在庫テストのdefault fixtureは36 variants、検索ページサイズは20または50のみ。既定順は`updated_desc`、同時刻はSKU昇順。BR-ADMININV-001の分類条件は0件、1〜5件、6件以上。
  - Native画面テストの未await `render()`は指定された3箇所のみで、画面実装にはassertion対象のtestIDが存在する。
  - Run root migration契約テストはUbuntu上のPowerShell実行を含まず、Windows jobは別のCodex Hook契約を実行する。WSL UNCパスをWindows PowerShellへ渡す環境差の可能性があるが、Windowsネイティブでの同一テスト結果は未確認。
- 前提:
  - TypeScript修正は対象4件を一括取得できる`pageSize: 50`への変更だけで成立する。型・API契約や分類ロジックは変更しない。
  - Native失敗群は同じ未await描画に由来する可能性が高く、テスト実行で確認する。
  - Windowsネイティブ成功runが確認できない場合、PowerShellスクリプトの安全検査を緩めず、環境依存の未確定事項として報告する。
- 対象外:
  - 製品機能追加・大規模リファクタリング、製品仕様の緩和、テスト削除・弱化。
  - Codex wrapper/rules-auto-netの復活、Run root/sanitizer/credential scan/Hook/sandbox/approval契約の変更。
  - merge abort/restart、commit、merge continue、push、PR merge。
