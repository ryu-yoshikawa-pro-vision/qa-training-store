# 新規AI協働QAカリキュラム構築Plan

## 結論と作業範囲

従来のテスト自動化カリキュラムを改訂する案は**採用しない**。既存課程を参照資料として調査する一方、学習目的・学習項目・教材・クイズ・実技・評価をゼロベースで組み立てた**独立した新課程**を構築する。

- 旧課程：`docs/curriculum/test-automation/`。**本文、Lesson ID、C01〜C12、既存104問、修了条件は変更しない**。
- 新課程：`docs/curriculum/ai-assisted-qa/`（Codex実装時に作成）。新しい学習目的、教材、問題と正答・解説、評価をここに収める。
- 新課程の専用演習が必要なら `training/ai-assisted-qa-course/` に配置する。既存 `training/agentic-qa/`（探索QA Challenge）とは別物である。既存の `training/playwright/` と `training/workbook/` は必要に応じて**参照・再利用**するが、旧課程の契約は書き換えない。
- 仕様・製品は従来どおり `docs/spec/` とScenario Shop本体を共通の正本とする。製品への追加実装は現在の前提では不要。必須演習の実行可能性が確認できない場合に限り、変更の要否を判断する。
- **本ブランチではPlanだけを修正する。教材・アプリ・スクリプト・CIの実装はCodexへ引き継ぐ**。旧課程のPR #198には変更しない。

## 設計の正本

以下の文書は、新課程に限った設計とする。過去の「17レッスンを維持する」「C13を旧評価へ追加する」「65問を固定する」「80%で一律合格」は**廃止した判断**であり、実装に使わない。

1. [調査と旧課程の再利用境界](./2026-10-16_qa-curriculum-ai-agent-redesign_research.md)：既存教材・Training・評価契約の事実と、新旧の分離方針。
2. [新課程の学習目的・全体設計](./2026-10-16_qa-curriculum-ai-agent-redesign_design.md)：卒業像、段階的な11モジュールの初期案、必要な実技と到達能力。
3. [学習項目と理解水準](./2026-10-16_qa-curriculum-ai-agent-redesign_learning-map.md)：何を学び、説明・適用・判断のどの深さまで求めるか、学習順序と評価方法。
4. [クイズ・正答・解説](./2026-10-16_qa-curriculum-ai-agent-redesign_quizzes.md)：出題範囲と形式、正答・選択肢別解説・根拠・復習先の定義と例。
5. [達成・採点・修了基準](./2026-10-16_qa-curriculum-ai-agent-redesign_assessment.md)：知識と実技の評価、再確認、達成条件、旧課程から独立した修了判定。
6. [Scenario Shopと実行環境](./2026-10-16_qa-curriculum-ai-agent-redesign_target.md)：必要なSeed・実技、コード配置、正式テスト・旧課程との分離、検証と受入条件。

## 設計する順番

1. **卒業像**：新しい仕様・テスト対象に対してAIエージェントを使い、分析→設計→Web自動化→実行・失敗分析→PR・CIまで、自分で検証・判断できること。
2. **能力と理解水準**：学習項目を「説明できる」「具体条件に適用できる」「妥当性を判断できる」に分解し、必要な基礎と前提順を確定する。
3. **評価方法**：客観的な知識確認は正答・解説付きクイズ、実践能力はScenario Shopでの演習と成果物、判断力はAI案のレビューと根拠を使って確認する。
4. **レッスン構成**：学習目標と評価に必要な教材だけを新規作成する。M00〜M10の11モジュールは初期案。**旧17レッスンとの数・順序の一致を目標にしない**。
5. **環境・運用**：受講者用の隔離コピーと新課程専用の保存・検証経路を用意する。既存の資産を共有する場合は読み取り・参照を優先し、旧課程の採点条件・CIへ副作用を与えない。

## Codexによる実装順序

1. 実装前にPR #198と作業ブランチの最新状態、旧課程のvalidator・Completion Receipt・Training Copy・workflowの依存関係を確認する。
2. `docs/curriculum/ai-assisted-qa/`に新課程の入口、学習目標、評価基準、モジュールを作成する。既存の `docs/curriculum/test-automation/` は一切編集しない。
3. [学習項目表](./2026-10-16_qa-curriculum-ai-agent-redesign_learning-map.md)から必要な説明・例・クイズ・解答解説・実技と評価項目を作る。問題数は目標の網羅性で決め、設計表に不足を残さない。
4. 受講者がクイズ回答後に正答と誤答の理由を確認でき、誤答した学習項目に戻れる構成を作る。独立したWebアプリや採点サービスは現時点で要求しない。
5. 新課程の実技が必要なら `training/ai-assisted-qa-course/` を追加する。既存のReset、Seed、Playwright helperを利用できるか検証し、旧課程の提出物やCLIに影響する改変は行わない。
6. OpenCodeと `qa-workflow-skills` の現行revisionを隔離環境で確認し、必要なSkillと補助スクリプトを使った最小実演を行う。実行不能ならBLOCKEDとし、教材を実証済みと書かない。
7. 新課程用のリンク・クイズ形式・学習目標との対応・実技提出物を検証する。必要なら**別の検証スクリプト／コマンド**を追加し、既存 `validate:curriculum` と `training:completion:check` の意味を変更しない。
8. 旧課程の検証を回帰テストとして実行し、新課程の検証結果と分けて報告する。PR・CIへの書き込みや有料実行は環境と権限を確認して必要なものに限定する。

## 新旧の境界と変更禁止

| 対象 | 新課程での扱い |
| --- | --- |
| `docs/curriculum/test-automation/**` | **編集・移動・削除しない**。参照のみ |
| `scripts/validate-curriculum.ts` / `scripts/training/check-completion.ts` | 旧課程専用の契約として維持。新課程用に流用・仕様変更しない |
| `training/workbook/**` / `training/playwright/**` | 教材・helperの読み取りや安全な再利用は可。既存課題・提出物・実行入口の挙動は変更しない |
| `training/agentic-qa/**` / `.agents/skills/exploratory-qa/**` | 既存の別目的の探索・採点用基盤。新課程として改名・移動・統合しない |
| `docs/spec/**` / `src/**` / `e2e/web/**` / 正式CI | 正本・実装・回帰の責務を維持。教材のための不具合注入をしない |
| `package.json`、共有設定、workflow | 新課程の独立実行に不可欠な**追加的**変更だけ可。既存スクリプト・job・制約を変更しない。変更理由と回帰を説明 |
| 新設 `docs/curriculum/ai-assisted-qa/**` / `training/ai-assisted-qa-course/**` | 新課程の教材・クイズ・実技・評価の専用領域 |

## 設計・実装の完了条件

**設計完了**：卒業像・各モジュールの学習項目・理解水準・評価方法・教材とクイズの形式・実技と合格の条件・新旧の責務分離・未実証事項を明文化している。問題全文の作成と実行確認はCodexの実装範囲。

**実装完了**：新課程だけで、説明→問題回答→正答解説・復習→実技→評価→次への進行ができる。学習項目に評価漏れがなく、新しい対象に知識を転用する総合演習が成立し、旧課程と正式テストの契約は維持される。

**今回の変更**：このPlan群のみ。実装・PR作成・merge・branch削除・force pushは行わない。
