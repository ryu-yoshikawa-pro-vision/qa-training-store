# Phase 2前半 Route Inventory

更新日: 2026-08-02（JST）

## 判定ルール

- `app/**/*.tsx` はWeb入口、同じパスの `*.native.tsx` はNative入口とする。
- Native前半の実装対象はGuest Storefront、Product、Search、Category、Cart、Guide、Legalである。
- Login、Account、Checkout、Order、Review、Admin操作は後半対象であり、Nativeでは安全な対象外画面を表示する。
- `/admin/test-control` のNative routeはUIを提供せず、Test Controlはroot bridgeのDeep Link経路だけを使う。

## Dependency / validation boundary

- Native routeの静的検査は `pnpm run check:native-route-dependencies` で行い、Web CSS、Dexie、React Aria、Browser Storage、Web entryの混入を拒否する。
- Native Rootは `NativeAppRuntimeProvider`、`NativeShell`、`NativeTestControlBridge`だけを組み合わせる。Application層はInfrastructureをimportしない。
- Test Controlは `scenario-shop://test-control/reset` のVersion 1 protocol、local／automation guard、reset mutex、Ready／Error signalを持つ。Production buildではbridge handlerを有効化しない。
- EAS設定・EAS Workflow・EAS Submitはユーザー方針により本Inventoryの対象外である。Native Buildはローカル経路でのみ検証する。
