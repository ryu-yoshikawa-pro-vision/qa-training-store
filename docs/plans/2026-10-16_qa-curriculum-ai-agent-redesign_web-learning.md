# 新課程のWeb閲覧・確認クイズ・受講者の学習体験

## 目的と対象

新課程M00〜M10の教材を、GitHubやCodespacesの起動前でも**公開Webページから閲覧**できるようにする。各モジュールの確認クイズは、**1問ずつ回答し、全問終了後に結果と解説を確認**できる形式とする。

教材・クイズの内容の正本は引き続き`docs/curriculum/ai-assisted-qa/`のMarkdownとし、公開Webは閲覧・練習の入口である。**現存する`docs/curriculum/ai-assisted-qa/README.md`は知識グラフの管理用説明であり、受講者の入口には使わない。** 受講者用の`start-here.md`を新たに作り、Webの新課程トップへ対応付ける。管理用READMEは既存参照とともに維持し、受講者向けナビゲーションからは外す。**Webクイズの点数は知識確認の参考であり、Level 2・フェーズの正式修了を自動判定しない**。実技、提出物、本人の根拠判断、評価者の確認は[評価Plan](./2026-10-16_qa-curriculum-ai-agent-redesign_assessment.md)に従う。

旧課程の`/docs/curriculum/`とその公開ページは維持する。新課程は独立した`/docs/curriculum/ai-assisted-qa/`配下に公開し、旧課程のURLや本文を置き換えない。

## 受講者が辿る導線

1. **入口（Web）**：新課程の目的、対象者、準備物、3フェーズ（Phase 3は選択）、M00〜M10の構成、Web閲覧とCodespaces実技の違い、費用・Secretへの注意を確認する。教材の閲覧と学習用クイズはGitHubログイン不要とする。実技開始時には本人のGitHubアカウントとCodespacesが必要なことを案内する。
2. **モジュール一覧（Web）**：フェーズ別に順序・学習目標・前提・実技の有無を示す。選択したモジュールの本文へ移動でき、先行モジュールや次のモジュールへ戻れる。Phase 1のみ／Phase 1＋2／Phase 3まで、受講範囲に合う終了地点と修了の意味を示す。
3. **モジュール本文（Web）**：最初に「何を学ぶか・前提・到達条件・必要な準備」を提示し、用語・手順・根拠付き完成例→誘導演習→本人の実技→確認クイズ→復習先の順に読める。正式仕様へのリンクはWeb版を優先し、必要なコード・Seed・Skillの参照も辿れるようにする。画面は目次・パンくず相当の戻り導線・前後のモジュール・現在地を示す。
4. **実技への移動**：Web上には受講者本人による`pnpm course:load Mxx`、Codespacesでの実行方法、作業フォルダ、提出物、戻る先を案内する。**WebボタンでCodespaces操作・課題ロード・AI実行を自動化しない**。教材本文はWebでも読めるが、Phase 1・2の実技は配布済みの学習用リポジトリで行う。公開Webの最新版と受講者の教材revisionが異なる場合に取り違えないよう、教材の版・参照先を表示し、受講中の教材を自動更新しない。
5. **確認クイズ（Web）**：各モジュールの本文から対応するクイズへ進み、結果を確認した後は間違えた学習項目の説明へ戻れる。次のモジュールへ進む操作は本人が行い、クイズの終了によって次の課題を自動ロードしない。
6. **フェーズ終了**：Web上に振り返りと正式な修了評価の案内を置く。M04/M07/M10の総合演習・非公開評価資料・評価担当者による正式判定を、Webクイズの点数で代替しない。Phase 3未受講でもPhase 1・2の導線が完結する。

## クイズ画面と操作の契約

- **開始**：モジュールID・題名・問題数・取り組み方を確認して「開始する」。問題順はMarkdown上の正規順とし、今回の範囲でランダム出題・制限時間・問題バンクを追加しない。
- **1問ずつ**：画面に`第n問／全N問`、設問・必要な条件・A〜Dの四択を1問だけ表示する。選択して「次へ」で進む。最初以外は「前へ」で戻って回答を変更できる。未回答で次へ進む／結果を確定する操作は防止し、何をすべきか分かるメッセージを表示する。
- **正答の表示時点**：途中では正答・得点・選択肢の解説を表示しない。最後の問題で全問回答を確認してから「結果を確認」を実行する。回答の変更は結果確定まで可能とする。
- **結果**：全問回答後に正答数／問題数、正答率、回答内容と正誤、問題ID・学習項目ID、正答、各選択肢の意味と正誤理由、根拠・復習先を確認できる。誤答だけを確認できる導線と、対象の教材節へ戻るリンクを用意する。誤答後は復習先から**別条件で再確認**できる手順を案内する。
- **再挑戦**：「最初からやり直す」を本人が選んだときだけ、そのモジュールの回答・結果をリセットする。他モジュールの状態と実技成果物は変更しない。復習・再挑戦で元の採点結果を正式修了に読み替えない。
- **中断・再開**：同じブラウザ・端末でページを再表示しても、そのモジュールの選択済み回答と現在位置を復元できるようにする。ブラウザ標準の`localStorage`にモジュールIDと問題のrevision（または問題ID集合が区別できる版）、選択肢と進行位置、結果確定状態のみ保存する。公開の採点サーバーへ送信しない。保存が利用できない場合も回答・結果表示は成立させ、再開できない旨を案内する。版が異なれば古い回答を新版の結果へ自動流用せず、再開始を案内する。共用端末では保存データの削除方法を案内する。
- **アクセシビリティ**：ラジオボタンと関連付けた設問、キーボード操作、明確なフォーカス、現在問数・エラー・結果の読み上げ、画面幅に応じた配置、適切なコントラストを満たす。回答操作はポインタ限定にしない。通信断でも読み込み済みの問題の操作はでき、保存できなかった場合に架空の保存完了を表示しない。
- **異常時**：問題ゼロ件、問題/解答の不一致、同一ID、A〜D欠損、正答が0件または複数、復習リンク欠損を含む不正な教材はビルド時に拒否する。公開済みページで必要なデータ取得に失敗したときはエラーと再読み込み手段を示し、0点や全問不正解として扱わない。

## データ・公開・実装方針

- **一次情報**：[クイズPlan](./2026-10-16_qa-curriculum-ai-agent-redesign_quizzes.md)の`quizzes/Mxx.md`（設問）と`quizzes/answers/Mxx.md`（学習用の公開解説）を使う。Web専用の手入力JSON・問題DBを正本として増やさず、ビルド時に表示用データを生成する。Markdownの問題ID・A〜D・正答・説明・根拠・復習先を対応させる。新課程のモジュール学習項目・教材節との関係は[知識グラフ完成仕様](./2026-10-16_qa-curriculum-ai-agent-redesign_knowledge-graph.md)と照合する。
- **既存基盤を再利用**：`scripts/docs/build-docs.ts`、`scripts/spec/markdown.ts`、`build:web`が公開中の旧課程`/docs/curriculum/`を生成している。そこに**新課程の独立URL群**と確認クイズ用の最小限のHTML/CSS/ブラウザJavaScriptを追加する。旧ナビゲーション・ビルド・公開Smokeを壊さない。新規Webアプリ、React画面の全面複製、CMS、認証、サーバーAPI、成績DB、学習管理サービス、外部の問題表示サービスは作らない。
- **公開データの限界**：公開クイズの正答・解説は公開教材であり、静的配信ファイルやGitHubから閲覧可能なため**秘匿・不正防止の保証はしない**。Web上では結果確定後に解説を表示する。非公開修了課題の模範解答・評価用テスト・個人の提出物は公開ビルド・配布物・Git履歴へ入れない。静的ページに認証情報・個人情報を埋め込まない。
- **URLの例**：入口`/docs/curriculum/ai-assisted-qa/`、モジュール`/docs/curriculum/ai-assisted-qa/modules/M03/`（最終的な静的HTMLの表記に合わせる）、確認クイズ`/docs/curriculum/ai-assisted-qa/quizzes/M03.html`。旧課程`/docs/curriculum/`とURLを衝突させない。
- **配布の扱い**：既存の管理者用許可リスト同期はMarkdown教材・未完成実技を配布する責務のままとし、Web閲覧は正本の公開ビルドが担当する。学習用Templateでも教材・クイズをMarkdownで読めるように維持し、Web UIが使えない場合でもCodespacesでの実技を妨げない。二つの正本を作らない。

## 実装手順と受入条件

1. 既存`scripts/docs/build-docs.ts`の旧課程生成・静的URL・仕様リンク・画像処理・公開Smokeを確認し、新課程の教材ページとナビゲーションを追加する。**存在しないM00〜M10の実教材を完成として表示しない**。教材が揃ったモジュールから、前提・学習範囲・必要な実技が見えるようにする。
2. 公開クイズMarkdownの安定した構造を検証し、設問・解説からWeb表示用データを生成する。学習用クイズの公開解説のみ使い、修了課題の非公開模範を読み込まない。破損・不足・複数正答・リンク切れをビルドで拒否する。
3. 1問表示→回答→次/前→全問回答→結果→問題別解説→復習→再挑戦と、中断・再開／revision相違／保存不可の経路をブラウザで検証する。誤答しても「クイズ失敗＝正式修了不可」と機械判定しない。
4. M00〜M10の教材ページ、各クイズと解説、Phase 1だけでの終了とPhase 3選択、Codespaces起動/ロード案内、正式評価へのリンクを、**Gitやプログラミング未経験の人が講師の補足なしで辿れるか**検証する。教材のわかりにくさ・ページ迷子・実技開始の迷いを記録して修正する。
5. Desktopとスマートフォン幅、キーボード、画面リーダーでの基本導線、公開URL直アクセス、ビルドとデプロイ後のページ表示、旧課程の非回帰を確認する。問題/解答の生成データ、Scriptの文字列・URLは既存の安全なエスケープ手段を使い、教材本文から任意のScriptを実行させない。
6. **完成判定**：新課程11モジュールをWebで閲覧でき、対応する全クイズが一問ずつの回答・結果・復習まで動作し、公開教材と非公開評価の境界、既存の旧課程Web、学習用Template/Codespaces、3フェーズの学習・修了評価を維持できること。代表教材で先に動線・理解・操作を検証してから全量制作へ展開する。

## 除外すること

Web上でのPlaywright実行、Skillのリモート実行、CodespacesやGitHubリポジトリの自動作成、クイズのサーバー採点、アカウント別成績管理、講師向け成績ダッシュボード、受講者の正式修了の自動認定、旧課程の画面改修は本件に含めない。
