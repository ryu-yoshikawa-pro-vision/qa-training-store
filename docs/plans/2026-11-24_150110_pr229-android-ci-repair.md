## 10. 調査後の判断

- Foojay `1.0.0`はGradle Plugin Portalの公式掲載に存在し、既存React Native Gradle plugin設定はPlugin Portalを含む既定repositoryを検索する。attempt 2はProductionのみplugin解決失敗、attempt 3はAutomationのみ同じ箇所で失敗し、ジョブ種別に固定されない。ログはHTTP/DNS/TLS statusを提供しないため、Gradle/RN/Java/repository設定の変更やworkflow retry追加はまだ正当化されない。
- NDK ZIP errorはattempt 2のAutomationで発生し、`SoftwareComponent 'release' not found`はNDK install failure後の二次エラー。attempt 3 ProductionではSDK準備の後にNDK `27.0.12077973`と`27.1.12297006`を取得しExpo SQLite buildとAPK verifyが成功したため、SDK preinstall変更は不要と判断する。AGP 8.12.0のdefault NDKが27.0.12077973、生成root projectのNDKは27.1.12297006。`expo-sqlite@57.0.5`と`.7`のGradle script差はversion文字列のみ。
- ローカルのfrozen installは一度のregistry timeout後に再実行成功。Expo Doctor初回16/17、次の診断起動は`EAI_AGAIN`で未実行。GitHub Native Staticの17/17とは区別し、外部依存のローカル到達性差を疑うが原因を断定しない。
- Web original CI run `45207272829`はstarting SHAでSUCCESS。最終merge受入はcommit/push後の最終HEAD Web/Mobile CIが両方SUCCESSとなるまで行わない。
