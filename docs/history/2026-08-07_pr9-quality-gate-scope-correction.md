# PR #9 品質ゲート対応方針の訂正（2026-08-07）

## 背景

前回の品質ゲート対応方針は、変更範囲外のエラーを即時保留せず、影響可能性または安全な最小修正があれば現在のPRで対応する内容だった。これは「既存エラー」というラベルだけで影響調査を省略しないための判断記録である。

PR #9再修正では、品質ゲート対応がサニタイザー、Native Maestro、CI、型、Jest、Vitest、文書へ広がり得ることを再確認した。安全に修正できることだけでPRへ追加すると、因果関係のない問題まで同じPRへ混在させるため、正本の方針を訂正する。

## 訂正後の判断

1. 品質ゲートの失敗は、変更範囲外と即断せず、Baseline、変更差分、共有依存、CI／テスト契約、実行環境との因果関係を調査する。
2. 現在の変更が原因である、または現在の変更を正しく検証するために不可欠である場合だけ、現在のPRで最小修正する。
3. 現在の差分と因果関係がなく、独立して修正可能な問題は、安全に修正できても現在のPRへ追加せず、別PRまたはユーザー承認後の対応候補としてRun Artifactへ記録する。
4. `defer`／`needs_human`とする場合は、「既存」「範囲外」だけでなく、因果関係の評価、影響、未実行検証、次アクションを記録する。

この文書は過去の判断を上書きせず、PR #9再修正時点の訂正を記録する。正本は`AGENTS.md`、`docs/reference/repair-loop.md`、`docs/PROJECT_CONTEXT.md`とする。
