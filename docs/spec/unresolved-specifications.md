# 未確定仕様

このファイルでは、プロダクトとしての仕様や意図が未確定の項目のみを記録します。ここに記載されている項目は、期待される動作の判断基準、不具合の判定、および採点基準として使用してはいけません。

## 未解決の質問

- **共通動作を超えたプラットフォーム間の外観一致**: Webとネイティブで共通化する意味や情報の表示順は確定していますが、プラットフォーム固有のナビゲーションやタイポグラフィにおける完全なピクセル一致については、仕様上の意図として未確定です。そのため、見た目の差異のみをもって不具合とは判定しません。方針決定の確定時に `ui-ux-contract.md` と対応するテストを更新します。

## 解決

プロダクトの意思決定が確定した項目は、正式な機能仕様書へ移行し、必要なBR/AC、自動テスト、チャーターを更新した上で、この一覧から削除します。
